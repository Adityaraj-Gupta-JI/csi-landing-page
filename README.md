# CSI Student Chapter — GenZ Neobrutalist Portal 🚀

A high-performance, single-file SPA (Single Page Application) built with raw semantic nodes and zero heavy compilation framework overhead. This portal leverages a GenZ Neobrutalist design system featuring flat categorical fills (Ghost Pink, Cyber Yellow, Neo Mint, Cyber Teal), thick structural boundaries, and asynchronous animation mechanics to deliver lightning-fast client interactions.

---

## ⚡ Design System Philosophy

This portal intentionally diverges from traditional tech-corporate design aesthetics (glassmorphism/ambient neon blurs) by introducing **GenZ Neobrutalism**. 

### Core UI Framework Rules:
* **Flat Architecture:** Zero ambient canvas gradients or soft drop-shadow blurs.
* **Stark Grid Contrast:** Layout elements utilize crisp 4px thick `#000000` boundaries.
* **Asymmetric Projections:** Shadows use literal `6px` flat vector offsets with 0px blur parameters to simulate structural depth.
* **Accessible Saturation:** Color blocks are paired precisely with high-contrast text layers to maintain absolute accessibility compliance.

---

## 🛠️ Tech Stack & Systems Engine

To achieve maximum edge delivery efficiency and an instant response runtime, the system uses zero server-side compilation frameworks:

* **Markup:** Semantic HTML5 Engine
* **Style Framework:** Tailwind CSS Engine (Utility-first client compilation)
* **Animation Core:** GSAP (GreenSock Animation Platform) + ScrollTrigger Extension
* **Routing Architecture:** Native Client-Side URL Hash Router Layer (`window.location.hash`)
* **Deployment Network:** Cloudflare Pages Global Edge Nodes
